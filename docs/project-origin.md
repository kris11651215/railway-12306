# 项目缘起

我是一名华东交通大学的学生。学校原隶属铁道部，是铁路人常说的"铁道嫡系"，身边不少校友扎根铁路一线。校友单杏花师姐是12306客票系统的技术带头人，她的工作让我看到：技术能够实实在在地支撑亿万旅客的出行。这也是我做这个项目的起点。

12306从不缺用户，缺的是更顺畅的体验：余票查询慢、换乘规划难、候补响应不及时、站内引导不精准。而这些痛点背后，是席位复用、票额分配、高并发扣减等真实而复杂的业务与工程问题——恰恰是练技术最好的题目。

因此，我想搭建"铁路智慧出行综合服务平台"：以AI为主线，把大模型能力落到智能购票助手、候补分析与动态加开建议上；以通用能力为基本盘，用Java、Spring Boot、MySQL、Redis实现余票查询、防超卖抢票与中转换乘规划；再结合广铁候补加开、广州南站站内引导等数智化实践做深度定制。它既是我的技术练习场，也是我作为华交学子对铁路的一次致敬。
